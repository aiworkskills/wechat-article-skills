# 贴图审稿清单

第 7 步用。**整组一起看**，不是一张一张单独看——组图的问题基本都是「放在一起才露出来」的。

## 基础检查

- [ ] 张数 ≤ 9（微信限制）
- [ ] 每张图有配文
- [ ] 配文无敏感词和错别字
- [ ] 配文与画面**互补**，不是把画面复述一遍

## 视觉检查（整组摊开看）

- [ ] 全组风格统一：色调、构图、字体、留白都是一套
- [ ] 第一张适合做封面 —— 缩略图尺寸下仍清晰可辨
- [ ] 图片比例统一（混比例在信息流里会显得像凑数）
- [ ] 无版权风险的元素（真实 logo、名人肖像、他人作品）
- [ ] 图内中文没有缺字、错字、断行错位

## 内容检查

- [ ] 图序读得通：按 `outline.md` 的叙事线从头翻一遍
- [ ] 配文与图片内容匹配
- [ ] 无敏感 / 争议性内容
- [ ] 品牌调性一致

## 交付前

按 [branches.md「一」](branches.md) 选定路径后再对应勾：

**A. 拼成图文发** —— 标题、摘要、作者已确认；`cover.*` 已就位；评论设置已确认。

**B. 只交付图** —— 已明确告诉用户「图片消息要在公众号后台手动发」，**没有**声称发布闭环完成。
