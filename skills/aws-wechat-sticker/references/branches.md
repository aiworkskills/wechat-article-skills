# 贴图的分支与细则

SKILL.md 只写主路径：定选题 → 定风格 → 排图序 → 生图 → 审图。本文件是**主路径之外才要读的东西**，主路径在对应位置用一行指过来。

---

## 一、发布这一步现在能做到什么 ⛔

**本套件没有实现微信的「图片消息」（`article_type: newspic`）接口。** `publish.py full` 走的是**图文草稿**：它硬性要求文章目录下同时有 `article.yaml`、`article.html` 和封面 `cover.*`，缺一个就报错退出。一个只有 `imgs/` 和 `outline.md` 的贴图目录跑 `full` 会直接失败。

所以贴图有两条落地路径：

**A. 拼成一篇图文发（本套件能全自动走完）**

1. 把 `outline.md` 的配文与图片写成一份 `article.md`：每张图一段 `![形态：画面](imgs/0N.png "配文")`，配文写在 title 参数里才会出图注。
2. 定标题、摘要、作者，跑 `article_init.py` 落 `article.yaml`。
3. 把第一张（或专门做的一张）复制/生成为文章目录下的 `cover.*`。
4. 跑 [formatting](../../aws-wechat-article-formatting/SKILL.md) 出 `article.html`，再走 [publish](../../aws-wechat-article-publish/SKILL.md) 的 `full`。

**B. 只交付图，用户自己在后台发图片消息**

产出 `imgs/` 里的整组图 + `outline.md` 里的配文，告诉用户「图片消息要在公众号后台手动发」。**这条路径下不要跑 `publish.py`**，也不要声称发布闭环完成。

**禁止**：在贴图目录上直接跑 `publish.py full` 然后把报错当成环境问题排查——那是这条路径本来就不通。

## 二、`image_create.py` 调用失败

与长文配图**同一套规则**，不另起一套：必须摘要 stderr 的关键行给用户，按**网络 / 配置·凭证 / 业务·参数**分类处理，**禁止**配置错误时静默降级。

完整的四分类表见 [images 的 branches.md「四、`image_create.py` 调用失败」](../../aws-wechat-article-images/references/branches.md)。

## 三、风格与形态的加载优先级

1. 用户当次指定（「用知识卡片风格」）
2. 本篇合并配置的 `custom_sticker_style` > `default_sticker_style`（**须为 YAML 字符串列表**；`custom_*` 非空时优先；多元素时**须先择一并写回本篇为单元素列表**）
3. `.aws-article/presets/sticker-styles/` 下的自定义风格
4. **兜底**：从共享的 [image-styles/](../../aws-wechat-article-images/references/image-styles/) 里按主题选一个形态

兜底时的九个形态分两类（与长文配图共用同一套定义）：

| 类别 | 形态 |
|---|---|
| **信息位**（看不懂才需要） | 流程步骤 · 结构分层 · 数据图表 · 对比两栏 · 清单要点 |
| **节奏位**（读不下去才需要） | 概念隐喻 · 场景还原 · 金句卡片 |

信息型贴图（知识卡片、产品功能）选信息位；氛围型贴图（节日、故事）选节奏位。**全组图统一一个形态**，不要每张换一个——组图的价值就在整齐。

## 四、贴图类型与叙事线

| 类型 | 说明 | 典型张数 |
|------|------|---------|
| 场景故事 | 用图片讲一个小故事 | 4-6 张 |
| 知识卡片 | 每张一个知识点 | 6-9 张 |
| 产品展示 | 产品多角度 / 多功能展示 | 3-6 张 |
| 节日祝福 | 节日主题图 + 祝福语 | 1-3 张 |
| 投票/互动 | 选项图片 + 引导文案 | 2-4 张 |

| 叙事逻辑 | 适用 |
|------|------|
| 场景递进 | 故事型：从早到晚、从起因到结果 |
| 知识点递进 | 教程型：从易到难 |
| 并列展示 | 清单型：每张独立但主题统一 |
| 对比 | 评测型：A vs B 交替展示 |
| 悬念揭晓 | 互动型：前几张设问，最后揭晓 |

## 五、「九宫格」指的是什么

指**一张图内部**排成 3×3 网格的构图（多主题概览，每格一个主题、统一色调），模板见 [prompt-construction.md](../../aws-wechat-article-images/references/image-styles/prompt-construction.md)「九宫格模板」。

**不是**把九张独立的图拼成一张——本套件**没有拼图脚本**。要九张独立图就是九张，靠 `outline.md` 保证风格与顺序统一。

---

## 六、单独安装

本 skill **至少要同时装** `aws-wechat-article-images`（生图）；要走发布再装 `aws-wechat-article-publish`。

只装本 skill 时，选题规划、图序、风格约定这些纯本地步骤仍可用，生图与发布步骤会在执行阶段遇到缺失文件。
