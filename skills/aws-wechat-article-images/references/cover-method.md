# 封面推导方法

这不是模板库，是一套流程。每篇文章走一遍，产出都不同。你是美术指导，图片模型是插画师：**给它一份 brief，不要给它一张清单。**

输入：文章（标题、摘要、正文）+ 账号的视觉语言（来自用户选的风格预设）+ `cover_aspect`。
输出：一个 prompt 文件（frontmatter 含 `aspect`，正文是一段有画面感的散文，标题文案写在里面）。

---

## 第一步：找核心张力

读标题、摘要、开头三段。问一个问题：**这篇文章里，什么变成了什么？**

用一句话写下来，必须含一个动词或一个对比：

- 「散落在聊天记录里的规矩 → 一次填进配置，之后自动加载」
- 「手工排版三小时 → 一条命令」
- 「以为要学 YAML → 其实填个表单」

如果写不出变化，就写它讲的那个**概念**：「记忆压缩」「上下文窗口」「技术债」。

写不出张力也写不出概念的文章，封面只能走氛围，跳到第四步。

## 第二步：定关系类型

第一步的句子属于哪一种，决定封面的骨架：

| 句子长什么样 | 类型 | 封面怎么做 | 适合 |
|---|---|---|---|
| A 和 B 并列对比 | **并置** | 两个东西并排放，让读者自己比 | 评测、前后对比、两种做法 |
| A 变成了 B、A 和 B 是一回事 | **融合** | 把两个东西合成一个物体，看得出是哪两个 | 转化、结合、同构 |
| 一个抽象概念 | **替代** | 用一个具体的物代替它 | 原理、方法论、观点 |
| 没有张力，只有情绪 | **氛围** | 不做隐喻，只做光和空间 | 随笔、故事、感悟 |

**融合**做成了最出彩，但最难；**替代**最稳。拿不准就替代。

## 第三步：找视觉隐喻

要一个**具体的、单一的、能画出来的**东西来承载第一步的句子。

方法：列三个候选，按三条筛：一眼能读懂、有一点意外、和这个号的调性搭。

**禁止的陈词滥调**（AI / 科技类文章尤其要躲）：机器人、发光的大脑、电路板做的大脑、伸出的机械手、握手、灯泡、齿轮堆、二进制雨、蓝色光环、抽象的「AI 赋能」光线。这些是模型的默认值，等于没给 brief。

范例（文章讲什么 → 隐喻 → 为什么成立）：

| 文章讲的 | 隐喻 | 类型 | 成立的理由 |
|---|---|---|---|
| 散落的规矩被收进配置 | 无数光点从四周汇聚成一个发光核心 | 替代 | 「汇聚」是动作本身，不解释也能懂 |
| 刚跑通的新流程 | 一株嫩芽顶开土壤，土屑还悬在半空 | 替代 | 「刚刚」被定格在那一瞬 |
| 拆解一套体系 | 一整张纸折出的微缩景观，折痕清晰可见 | 替代 | 折痕就是结构，看得见怎么拼的 |
| 只有一个出口 | 混凝土长廊尽头唯一的一道光 | 替代 | 纵深让「唯一」有分量 |
| 自然生长与工程设计同构 | 树根向下渐变成电路走线，无缝过渡 | 融合 | 两者共用同一条线，分不出边界 |
| 红利期终将过去 | 沙漏上半是运转的城市，下半是坍成沙的废墟 | 融合 × 对立 | 上下是同一件事的两端 |
| 一次优化前后 | 同一个几何体，左边是粗糙原石，右边是通透水晶 | 并置 × 对立 | 形状相同才让人比材质 |
| 那个没人提的问题 | 满座的会议桌，只有一把椅子被推开背对着 | 替代 × 对立 | 用缺席表达在场 |

这些是**范例不是模板**。同一篇文章换个隐喻完全可以，只要过得了三条筛。

## 第四步：选形态模板

从候选池（`custom_cover_image_style`，默认全选）里挑一个**内容形态**。判断只有一条：

> **这篇文章的主体，在 345px 宽的缩略图里能不能被一眼认出？**

| 能（自明） | 不能（抽象） |
|---|---|
| 一道菜、一个人、一处空间、一个情绪场景 | 一个方法、一个观点、一次对比、一套流程 |
| → 菜品特写 / 人物出镜 / 场景实拍 / 剧照氛围 | → 纯色大字 / 图上压字 / 信息表 / 数字冲击 / 对比式 / 截图标注 |
| **默认不加字**，主体自己会说话 | **字就是全部**，画面只是背景 |

介于两者之间的教程、产品评测 → 扁平插画 / 产品实拍，插画或产品打底 + 一句短钩子。

抽象类里有三个专用形态，命中就优先用：标题带数字 → **数字冲击**（放大数字做焦点，
100 大号分析里排第一）；讲前后/方案对比 → **对比式**（并置制造张力，排第二）；
讲怎么操作 → **截图标注**（红圈加箭头，工具号标配）。

选定后照抄该模板的五个字段：主体占比、影调、**文案规格**（字号、颜色、位置一字不改）、版式。文案规格是模板里最不能改的部分——它是按信息流尺寸标定过的。

同一篇文章换个形态完全可以，模板是默认值不是牢笼。但**不要跨类混用**：自明类加大字会挡主体，抽象类不加字等于没封面。

### 避免撞形

形态只有 12 个，一个账号发几十篇必然重复选到同一个。差异靠模板里的**可轮换维度**——
视角、容器、台面、光这类，每次各选一个值。实测同一形态、同一内容，只换维度值就能
拉开明显差异（俯拍粗陶暗木桌 / 45 度铸铁锅顶光 / 微距挑起大理石窗光，三张放一起
不像重复）。

Agent 应记录本账号最近 3 篇用过的「形态 + 维度组合」，新的一篇避开。同一篇文章内的
多张配图同理，避免几张配图撞形。

## 第五步：按信息流尺寸布局

封面在信息流里只有 **345×147px**（iPhone 逻辑像素，头条），次条更小。所有布局决定都要在这个尺寸下成立，不是在 1408×599 的原图上。缩到 345px 宽看不清的东西，等于不存在。

**标题是第一元素，画面是它的背景。** 不是反过来。

硬规矩：

- **标题 4–7 个字**，从文章标题里提炼最刺激的那个钩子。「网页配置台：把公众号规矩一次填清楚」→「规矩一次填清楚」；「为什么你的周报没人看」→「周报太淡了」
- **字高占画面高度 25–35%**，横向撑满它所在的那一半。低于 20% 在信息流里和微信自带的标题一样大，等于白写
- 粗体。浅底深字、深底浅字，对比拉满；深底可加柔和辉光
- 主体**占满画面高度的一半以上**，靠近标题。小主体在缩略图里只是一个点
- 视觉元素不超过 3 个（标题算一个）
- 除标题外画面里没有别的文字

布局二选一：**主体在左四成、标题在右六成**（默认），或**标题居中、主体做底**。别发明第三种。

1:1 分享卡片由 `pic_crop` 从中截取，是降级视图，不为它牺牲主图。

写进 prompt 时给出**确切文案、位置、字体感、颜色、大小**，例如：

> 画面右侧六成，用粗壮的黑体写「周报太淡了」，深炭灰色，字高约占画面高度的 30%，横向撑满右侧区域，这是画面里唯一的文字，也是画面的视觉中心。

## 第六步：写成散文

不是关键词，是一段能让人在脑子里看见画面的话。150 到 300 字。

顺序：**场景 → 主体细节 → 光 → 氛围 → 它像什么不像什么 → 标题**。

三个技巧：

- **正面描述**。要「空旷的街道」不要「没有车的街道」。「不要 X」经常把 X 召唤出来。
- **像什么、不像什么**。「像天文台的长曝光观测图，而不是一张科技海报」——这句话能纠正模型的默认审美。
- **写细节不写形容词**。「土屑还悬在半空」比「充满生机」有用得多。

一个完整例子（插画风，文章讲规矩收进配置）：

```
奶油白的背景，带一点纸张的纹理。画面左侧，几个手绘的圆角对话气泡散落着，
珊瑚红、芥末黄、薄荷绿各一个，气泡里只有波浪线。它们朝右排成一列，越往右
越规整，到最右边已经变成了一张表单：三行短横线加一个薰衣草紫的对勾。气泡
到表单之间是连续的，看不出在哪里变的。深棕色的手绘描边，柔和的圆角，没有
阴影，没有渐变。像一本现代绘本的扉页，而不是一张 SaaS 的功能截图。

画面右侧六成，用粗壮的圆体写「规矩一次填清楚」，深棕色，字高约占画面高度
的 28%，横向撑满右侧区域，这是画面里唯一的文字，也是画面的视觉中心。
```

## 第七步：回看

打开生成的图，对五条：

1. 标题的字对不对、全不全（模型偶尔会把「一」画成「5」）
2. 主体是不是在该在的位置，标题区有没有被侵占
3. 元素是不是不超过 3 个
4. **缩到 345px 宽**（信息流实际尺寸）还能不能一眼读出标题、认出主体
5. 和文章有没有关系，还是一张漂亮但无关的图
6. 形态选对没有——自明的主体被字挡住了？抽象的内容没有字？

不过关就**回到出问题的那一步改**：标题错了改第六步的文案写法；字小、主体小、缩略图糊成一团都是第五步没按信息流尺寸定；和文章无关是第一步没找准。不要不改 prompt 就盲目重跑。

**看不了图时的兜底只有两项。** `python {baseDir}/scripts/image_create.py check cover.png`
做的是尺寸与近单色检查，**不含标题区**。标题区那项测的是边缘密度（确认某块区域是空的、
可以往上贴字），只对**合成标题**那条路成立——本方法要求让模型把标题画进图里，标题文字
本身就是高边缘密度，硬套只会把每张正确的封面都判为不合格。所以上面六条仍须肉眼过，
代码兜底替不了。

## 附：风格预设应该长什么样

风格预设是账号级的，用户配一次，每篇文章都用。它**只描述视觉语言**：

```
# 插画

## 视觉语言
手绘扁平插画，柔和圆角，干净的矢量线条，轻微纸张纹理。

## 色板
珊瑚红 #FF6B6B、芥末黄 #FFD93D、薄荷绿 #6BCB77、薰衣草紫 #B4A7D6，奶油白底 #FDFBF7。

## 光与材质
平光，无阴影，无渐变。纸感。

## 气质
亲切、有创造感，但克制，不幼稚。

## 适合
教程、科普、个人成长、生活方式。
```

预设里**不该有**：具体的物体、具体的场景、构图指令、占位标题。那些每篇文章都不一样，是上面七步推出来的。
