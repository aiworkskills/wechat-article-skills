# 封面推导方法

这不是模板库，是一套流程。每篇文章走一遍，产出都不同。你是美术指导，图片模型是插画师：**给它一份 brief，不要给它一张清单。**

输入：文章（标题、摘要、正文）+ 账号的视觉语言（来自用户选的风格预设）+ `cover_aspect`。
输出：一个 prompt 文件（frontmatter 含 `aspect`，正文是一段有画面感的散文，标题文案写在里面）。

---

## 第一步：找核心张力

读标题、摘要、开头三段。问一个问题：**这篇文章里，什么变成了什么？**

用一句话写下来，必须含一个动词或一个对比：

- 「散落在聊天记录里的规矩 → 一次填进配置，之后自动加载」
- 「手工排版三小时 → 一条命令」
- 「以为要学 YAML → 其实填个表单」

如果写不出变化，就写它讲的那个**概念**：「记忆压缩」「上下文窗口」「技术债」。

写不出张力也写不出概念的文章，封面只能走氛围，跳到第四步。

## 第二步：定关系类型

第一步的句子属于哪一种，决定封面的骨架：

| 句子长什么样 | 类型 | 封面怎么做 | 适合 |
|---|---|---|---|
| A 和 B 并列对比 | **并置** | 两个东西并排放，让读者自己比 | 评测、前后对比、两种做法 |
| A 变成了 B、A 和 B 是一回事 | **融合** | 把两个东西合成一个物体，看得出是哪两个 | 转化、结合、同构 |
| 一个抽象概念 | **替代** | 用一个具体的物代替它 | 原理、方法论、观点 |
| 没有张力，只有情绪 | **氛围** | 不做隐喻，只做光和空间 | 随笔、故事、感悟 |

**融合**做成了最出彩，但最难；**替代**最稳。拿不准就替代。

## 第三步：找视觉隐喻

要一个**具体的、单一的、能画出来的**东西来承载第一步的句子。

方法：列三个候选，按三条筛：一眼能读懂、有一点意外、和这个号的调性搭。

**禁止的陈词滥调**（AI / 科技类文章尤其要躲）：机器人、发光的大脑、电路板做的大脑、伸出的机械手、握手、灯泡、齿轮堆、二进制雨、蓝色光环、抽象的「AI 赋能」光线。这些是模型的默认值，等于没给 brief。

范例（文章讲什么 → 隐喻 → 为什么成立）：

| 文章讲的 | 隐喻 | 类型 | 成立的理由 |
|---|---|---|---|
| 散落的规矩被收进配置 | 无数光点从四周汇聚成一个发光核心 | 替代 | 「汇聚」是动作本身，不解释也能懂 |
| 刚跑通的新流程 | 一株嫩芽顶开土壤，土屑还悬在半空 | 替代 | 「刚刚」被定格在那一瞬 |
| 拆解一套体系 | 一整张纸折出的微缩景观，折痕清晰可见 | 替代 | 折痕就是结构，看得见怎么拼的 |
| 只有一个出口 | 混凝土长廊尽头唯一的一道光 | 替代 | 纵深让「唯一」有分量 |
| 自然生长与工程设计同构 | 树根向下渐变成电路走线，无缝过渡 | 融合 | 两者共用同一条线，分不出边界 |
| 红利期终将过去 | 沙漏上半是运转的城市，下半是坍成沙的废墟 | 融合 × 对立 | 上下是同一件事的两端 |
| 一次优化前后 | 同一个几何体，左边是粗糙原石，右边是通透水晶 | 并置 × 对立 | 形状相同才让人比材质 |
| 那个没人提的问题 | 满座的会议桌，只有一把椅子被推开背对着 | 替代 × 对立 | 用缺席表达在场 |

这些是**范例不是模板**。同一篇文章换个隐喻完全可以，只要过得了三条筛。

## 第四步：套视觉语言

视觉语言来自用户选的风格预设，只管**怎么画**，不管**画什么**：色板、媒介、材质与光、留白倾向、气质。

把预设里的描述翻译成这张图的具体决定：

- 「科技风」→ 近黑的深蓝底、青色冷光、细线与网格、纵深感、冷峻
- 「插画」→ 奶油白底、珊瑚/芥末/薄荷/薰衣草、手绘扁平、圆角、纸纹、亲切但克制
- 「实拍」→ 浅景深、单一光源、胶片调色、有雾感、电影帧

第三步的隐喻要**用这套语言重画一遍**：同一个「嫩芽破土」，科技风是暗场里发光的芽，插画是奶油底上圆角的芽，实拍是微距逆光的真芽。

## 第五步：按 2.35:1 布局

信息流里那一眼是 2.35:1，按它构图。1:1 分享卡片由 `pic_crop` 从中截取，是降级视图，不为它牺牲主图。

默认布局：**主体在左侧三分之一，右侧留给标题。** 也可以主体居中、标题在下，或主体铺满上半、标题在下方空带。三选一，别发明第四种。

硬规矩：

- 视觉元素不超过 3 个
- 留白不少于四成
- 缩到 400px 宽还能看懂
- 标题区内除标题外什么都没有

**标题**：不超过 12 个字，从文章标题里提炼钩子。「网页配置台：把公众号规矩一次填清楚」→「规矩一次填清楚」。写进 prompt 时给出**确切文案、位置、字体感、颜色、大小**，例如：

> 右侧留白区域正中，用粗壮的无衬线黑体写「规矩一次填清楚」，白色，字高约占画面高度的 15%，这是画面里唯一的文字。

## 第六步：写成散文

不是关键词，是一段能让人在脑子里看见画面的话。150 到 300 字。

顺序：**场景 → 主体细节 → 光 → 氛围 → 它像什么不像什么 → 标题**。

三个技巧：

- **正面描述**。要「空旷的街道」不要「没有车的街道」。「不要 X」经常把 X 召唤出来。
- **像什么、不像什么**。「像天文台的长曝光观测图，而不是一张科技海报」——这句话能纠正模型的默认审美。
- **写细节不写形容词**。「土屑还悬在半空」比「充满生机」有用得多。

一个完整例子（插画风，文章讲规矩收进配置）：

```
奶油白的背景，带一点纸张的纹理。画面左侧，几个手绘的圆角对话气泡散落着，
珊瑚红、芥末黄、薄荷绿各一个，气泡里只有波浪线。它们朝右排成一列，越往右
越规整，到最右边已经变成了一张表单：三行短横线加一个薰衣草紫的对勾。气泡
到表单之间是连续的，看不出在哪里变的。深棕色的手绘描边，柔和的圆角，没有
阴影，没有渐变。像一本现代绘本的扉页，而不是一张 SaaS 的功能截图。

右侧留白区域正中，用粗壮的圆体写「规矩一次填清楚」，深棕色，字高约占画面
高度的 15%，这是画面里唯一的文字。
```

## 第七步：回看

打开生成的图，对五条：

1. 标题的字对不对、全不全（模型偶尔会把「一」画成「5」）
2. 主体是不是在该在的位置，标题区有没有被侵占
3. 元素是不是不超过 3 个
4. 缩小看还能不能读
5. 和文章有没有关系，还是一张漂亮但无关的图

不过关就**回到出问题的那一步改**：标题错了改第六步的文案写法；主体乱跑改第五步的布局描述；和文章无关是第一步没找准。不要不改 prompt 就盲目重跑。

## 附：风格预设应该长什么样

风格预设是账号级的，用户配一次，每篇文章都用。它**只描述视觉语言**：

```
# 插画

## 视觉语言
手绘扁平插画，柔和圆角，干净的矢量线条，轻微纸张纹理。

## 色板
珊瑚红 #FF6B6B、芥末黄 #FFD93D、薄荷绿 #6BCB77、薰衣草紫 #B4A7D6，奶油白底 #FDFBF7。

## 光与材质
平光，无阴影，无渐变。纸感。

## 气质
亲切、有创造感，但克制，不幼稚。

## 适合
教程、科普、个人成长、生活方式。
```

预设里**不该有**：具体的物体、具体的场景、构图指令、占位标题。那些每篇文章都不一样，是上面七步推出来的。
