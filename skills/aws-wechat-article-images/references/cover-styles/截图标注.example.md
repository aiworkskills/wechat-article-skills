# 截图标注

## 用于

工具教程、操作指南、功能介绍。**主体不自明**，但截图加标注能一眼说清「点哪里」。工具号标配。

## 主体

一个简化的应用窗口占画面左三分之二、高度 90%，界面上不写可读文字。关键位置用手绘感红圈圈住，引出红箭头。

## 影调

深灰背景衬托浅色 UI，窗口有清晰边缘和轻微投影。只有圈和箭头是红色，其余保持中性。

## 文案

**必须有。** 箭头指向的右侧空白区写 3–5 字红色极粗中文，字高占画面 22%。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **界面类型**：应用窗口 / 手机竖屏 / 网页浏览器 / 编辑器
- **标注形状**：椭圆圈 / 方框 / 下划线 / 圆点序号
- **箭头**：单条曲线 / 直线 / 多条分指 / 无箭头只有圈
- **背景**：深灰 / 米白 / 品牌色

## 版式

截图左三分之二，标注文字右三分之一。
