# 人物出镜

## 用于

健身、育儿、人物、经历分享。**主体自明**——人脸和身体是最强的注意力装置。

## 主体

一个人物占满画面高度九成，有明确动作或状态，不摆拍。

## 影调

逆光或侧光勾出轮廓，浅景深，背景虚化成光斑。纪实摄影质感，不是广告片。

## 文案

**默认不加字。** 人物状态已经说明一切。要加则用图上压字的规格。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **景别**：半身 / 全身 / 手部特写 / 背影
- **状态**：动作进行中 / 停顿喘息 / 专注凝视 / 转身回望
- **环境**：室内窗边 / 街头 / 工位 / 空旷户外
- **光**：逆光轮廓 / 侧光塑形 / 阴天散射 / 夜晚人造光

## 版式

人物偏左，右侧三分之一留虚化亮部。
