# 剧照氛围

## 用于

情感、故事、随笔、人生感悟。**主体自明**——传达的是情绪不是信息。

## 主体

一个人物的背影或剪影，只占画面高度一半，显得渺小；或一处有情绪的风景。

## 影调

黄昏或夜晚，天空大面积渐变，只有轮廓被边光勾出。整体偏暗。

## 文案

**默认不加字。** 情绪型封面加字会破坏留白。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **主体**：背影 / 剪影 / 局部特写 / 纯风景
- **时刻**：黄昏 / 深夜 / 雨天 / 雾晨
- **空间感**：开阔天台 / 狭窄走廊 / 车窗内 / 水边
- **色调**：橙蓝渐变 / 青灰单色 / 暖褐 / 冷蓝

## 版式

主体在左三分之一，右上大面积留空。
