# 扁平插画

## 用于

教程、科普、概念解释。介于自明与不自明之间——插画能表达抽象关系，配短字更稳。

## 主体

简化的几何造型人物或物件，无五官，靠姿态表达。元素不超过 3 组。

## 影调

奶油白底带纸纹，珊瑚红/芥末黄/薄荷绿配深棕描边，圆角，无阴影无渐变。

## 文案

**建议加字。** 4–7 字钩子，粗圆体，字高占画面 20%，排在右侧留白区。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **主体**：人物 / 器物 / 抽象几何 / 动植物
- **色板**：珊瑚薄荷 / 蓝黄对比 / 莫兰迪低饱和 / 黑白加一色
- **笔触**：粗描边圆角 / 无描边色块 / 细线勾勒
- **构图**：左图右字 / 上图下字 / 主体居中

## 版式

插画占左四成，右六成留给文字。
