# 产品实拍

## 用于

工具评测、产品发布、软硬件介绍。产品是主体但常需一句钩子点明观点。

## 主体

产品斜放在画面左侧四成，占画面高度七成，边缘有锐利高光。旁边一两件相关物件。

## 影调

深灰亚光台面，单一柔光从左上打来投出干净长影。冷色调。

## 文案

**必须有。** 4–7 字钩子，极粗黑体，**纯白色**（深底必须用纯白，浅灰在缩略图里会消失），字高占画面 26%，撑满右侧留白区。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **视角**：45 度斜放 / 正俯拍 / 侧面剪影 / 局部特写
- **台面**：深灰亚光 / 浅色木纹 / 纯白无缝 / 深色皮革
- **陪衬**：无 / 线缆 / 便签纸 / 一杯饮品
- **光**：左上柔光 / 顶部条光 / 侧向硬光勾边

## 版式

产品左四成，文字右六成。
