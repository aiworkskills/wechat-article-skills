# 对比式

## 用于

前后对比、方案 PK、认知反转。**主体不自明**，靠并置制造张力。100 个大号分析里排第二。

## 主体

画面左右等分为两个不同底色的半区，各放一个同类但状态相反的图形，大小与垂直位置严格对称。

## 影调

两半用冷暖对照的低饱和底色（灰蓝 / 暖橙）。图形单色，扁平无阴影。

## 文案

**必须有，且必须放在顶部的实心横幅上。** 横幅高占画面 24%，横贯全宽；白字粗体，字高占横幅 60%。放在两半交界处会被切顶——实测过。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **底色对**：灰蓝+暖橙 / 深灰+米黄 / 墨绿+砖红
- **图形**：缠绕线团vs平行线 / 碎块vs整块 / 歪斜vs对齐
- **横幅位**：顶部 / 底部
- **图形位**：下方三分之二 / 垂直居中

## 版式

顶部横幅放字，下方左右等分放图形。
