# 信息表

## 用于

清单、步骤、对比、盘点。卖的是信息密度感——缩略图里读不完是正常的，它传达「这里有干货」。

## 主体

3–5 个等距排列的圆角方块或表格行，用箭头或分隔线相连，每格两行极简中文。

## 影调

米白或浅灰背景，每格用不同的低饱和色。完全扁平，无阴影无渐变。

## 文案

**必须有标题。** 粗黑体标题居中在结构上方，字高占画面 14%。格内文字小是允许的。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **结构**：横向流程 / 纵向清单 / 二维矩阵 / 环形循环
- **格数**：3 格 / 4 格 / 5 格
- **配色**：低饱和多色 / 单色深浅 / 黑白加一个强调色
- **强调**：高亮当前格 / 加粗末格 / 全部等重

## 版式

标题在上，结构横向铺满中部。
