# 图上压字

## 用于

主体不自明的内容——观点、方法论、职场、AI。最通用的带字形态，照片给氛围，字给信息。

## 主体

一张实拍照片铺满画面，浅景深，单一光源。

## 影调

胶片调色，暗部提亮不死黑。照片下三分之一压一层由透明到深黑的渐变遮罩。

## 文案

**必须有。** 4–7 字钩子，纯白粗黑体，字高占画面 16%，左对齐排在遮罩上，从画面 8% 排到 62%。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **照片主题**：工位 / 街景 / 器物 / 人物局部
- **遮罩位置**：底部渐变 / 顶部渐变 / 左侧竖向 / 整体压暗
- **字位**：左下 / 居中 / 右下
- **光**：夜晚人造光 / 逆光 / 阴天散射

## 版式

照片铺满，文字压在下三分之一。
