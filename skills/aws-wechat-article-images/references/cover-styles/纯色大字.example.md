# 纯色大字

## 用于

观点、评论、方法论、干货——主体不自明的抽象内容。信息流里靠字抓人，不靠画面。

## 主体

没有主体，或一个极简符号占画面高度 30% 以内。

## 影调

单一高饱和实色底，无渐变无纹理。深底浅字或浅底深字，对比拉满。

## 文案

**这是画面的全部。** 4–7 字钩子，极粗无衬线黑体，字高占画面 35–40%，横向占 45% 以上，居中。可在下方加一行字高为主标题四分之一的副标题。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **底色**：深墨绿 / 砖红 / 靛蓝 / 炭黑 / 芥末黄
- **字色**：纯白 / 米白 / 与底色互补的高饱和色
- **符号**：无符号 / 一个几何标记 / 一个标点 / 一个数字
- **排列**：单行居中 / 两行左对齐 / 主副标题上下

## 版式

文字居中，上下留白相等。
