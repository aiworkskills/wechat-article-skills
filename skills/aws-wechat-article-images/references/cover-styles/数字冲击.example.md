# 数字冲击

## 用于

带数字的选题——「3 倍」「20 分钟」「7 个方法」。**主体不自明**，靠数字的体量抓眼。100 个大号分析里排第一的方法：数字天然比文字更吸引眼球。

## 主体

一个极大的阿拉伯数字占画面高度 70%，是绝对主角。数字旁一个小单位字，右侧一行说明短语。

## 影调

单一深色实色底，数字用高饱和亮色，说明字纯白。无渐变无纹理，对比拉满。

## 文案

**数字就是主体。** 数字占高 70%；单位字为数字的五分之一；说明短语 4–6 字，字高占画面 18%，垂直居中对齐数字。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **底色**：深靛蓝 / 炭黑 / 墨绿 / 砖红
- **数字色**：芥末黄 / 亮橙 / 荧光绿 / 纯白
- **单位位置**：数字右下角 / 数字右上角 / 无单位
- **说明位**：数字右侧 / 数字下方

## 版式

数字偏左，说明短语在右，垂直居中。
