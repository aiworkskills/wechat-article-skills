# 场景实拍

## 用于

生活方式、空间、职场场景、旅行。**主体自明**——空间本身是主角，无需人物。

## 主体

一处有细节的真实空间，前景有一两件具体物件锚定视线。通常无人。

## 影调

一束方向明确的自然光穿过空间，光里可见浮尘。暖调，暗部保留细节。

## 文案

**默认不加字。** 要加则用图上压字的规格。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **空间**：室内一角 / 街道 / 桌面俯视 / 窗前
- **时间**：清晨斜光 / 正午硬光 / 黄昏暖光 / 夜晚灯下
- **前景锚点**：一件器物 / 一本翻开的书 / 一杯饮品 / 一双鞋
- **有无人迹**：空无一人 / 只留痕迹 / 远处有模糊人影

## 版式

前景物件清晰在近处，纵深处柔化。
