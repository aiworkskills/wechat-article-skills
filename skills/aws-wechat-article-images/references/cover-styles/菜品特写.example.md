# 菜品特写

## 用于

美食、食谱、探店。**主体自明**——一碗面就是一碗面，缩略图不需要解释，加字反而挡菜。

## 主体

成品菜肴占满画面高度 85%，俯拍或 45 度。真实质感：热气、油光、手作痕迹。

## 影调

暖色，侧逆光让热气和油光发亮。粗陶、木桌、亚麻这类有质感的底。

## 文案

**默认不加字。** 需要强调做法或结论时，才在顶部或底部压一条字高 12% 的粗字，白字配深色半透明底。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一账号连续几篇撞形。
Agent 应记录本账号最近 3 篇用过的组合并避开。

- **视角**：俯拍平铺 / 45 度侧俯 / 微距挑起 / 手部入镜
- **容器**：粗陶碗 / 白瓷盘 / 黑铸铁锅 / 竹编屉
- **台面**：深色胡桃木 / 浅色大理石 / 灰亚麻布 / 水泥
- **光**：右上侧逆光 / 左侧窗光 / 顶光直下

## 版式

主体居中或偏左。2.35:1 与 1:1 都成立——美食号大量直接用方图。
