# 对比两栏

## 用于

前后对比、方案对比、好坏对照。**信息位**——删掉读者抓不到差异。

## 主体

一条细竖线把画面分成等宽两栏，每栏顶部一个色标签，下面 3–4 行带勾/叉的条目。

## 影调

米白背景，左栏砖红、右栏墨绿。扁平，无阴影。

## 文案

**必须有真实对比项。** 两栏行高严格对齐，方便横向比较。

## 媒介

默认**马克笔白板**——中间一条马克笔竖线，左红叉右绿勾，手写行楷。

本篇所有信息位配图共用同一媒介，由 [image-method.md](../image-method.md) 第四步按 `tone` / `account_type` 定；换成扁平矢量会有明显 AI 味。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **分隔**：细竖线 / 色块底 / 中间留白 / 斜切
- **条目数**：2 条 / 3 条 / 4 条
- **符号**：勾叉 / 上下箭头 / 表情符 / 纯色点
- **配色**：红绿 / 灰蓝 / 暖冷对照

## 版式

左右等宽，16:9。
