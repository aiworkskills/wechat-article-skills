# 场景还原

## 用于

使用场景、日常情境、代入感段落。**节奏位**。

## 主体

一个真实动作的局部特写（手在操作、物件在使用中），不拍全景不拍脸。

## 影调

浅景深，窗光或自然光，暖调，柔和阴影。真实临场感，不是图库摆拍。

## 文案

**不加字。**

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **部位**：手部 / 桌面 / 屏幕 / 背影局部
- **动作**：正在操作 / 刚放下 / 伸手去拿 / 静止陈列
- **光**：窗光 / 台灯 / 阴天散射 / 屏幕反光
- **色调**：暖木色 / 冷灰 / 米白 / 深夜暖黄

## 版式

主体偏一侧，另一侧留虚化空间。
