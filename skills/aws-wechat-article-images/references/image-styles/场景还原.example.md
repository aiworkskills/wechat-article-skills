# 场景还原

## 用于

使用场景、日常情境、代入感段落。**节奏位**。

## 主体

**文章里写到的那一个具体时刻的局部特写**，不拍全景不拍脸。

关键在「那一个」。prompt 里必须写进一个只有这篇文章会有的细节——文中提到的那个物件、那个时间、那个动作的中间状态。缺了这个细节，模型给出的一定是「手放在笔记本电脑上，旁边一杯咖啡」——那是全互联网最烂大街的一张图，不带 AI 味，但带图库味，是同一种病。

怎么写具体：

- 有名字的物件：不写「一份文档」，写「一张写满红批注的打印稿」
- 有中间状态：不写「在打字」，写「手指停在键盘上方，屏幕上光标停在一句话中间」
- 有时间痕迹：冷掉的茶、烧到一半的香、屏幕上已经熄灭的提示

三条至少占两条，否则重写。

## 影调

浅景深，窗光或自然光，暖调，柔和阴影，画面里有生活痕迹——用旧的物件、没收拾干净的桌面、随手放歪的东西。

## 文案

**不加字。**

## 媒介

不参与本篇的媒介统一——它是实拍，按本模板的影调走。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **部位**：手部 / 桌面 / 屏幕 / 背影局部
- **动作**：正在操作 / 刚放下 / 伸手去拿 / 静止陈列
- **光**：窗光 / 台灯 / 阴天散射 / 屏幕反光
- **色调**：暖木色 / 冷灰 / 米白 / 深夜暖黄

## 版式

主体偏一侧，另一侧留虚化空间。
