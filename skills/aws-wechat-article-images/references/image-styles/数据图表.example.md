# 数据图表

## 用于

数据、趋势、指标、报告。**信息位**——删掉读者看不到量的变化。

## 主体

柱状条或折线，末端关键点放大标注。纵轴不画刻度线，只留极淡水平网格。

## 影调

米白背景，单色系渐变（如浅灰到墨绿）。克制，像严谨报告的插图，不是商业海报。

## 文案

**必须有真实数字与标签。** 数值标在柱顶或点旁，横轴标签用中文。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **图型**：柱状 / 折线 / 面积 / 柱线组合
- **排列**：纵向柱 / 横向条 / 双轴对照
- **配色**：单色深浅 / 双色对比 / 灰底加一个强调色
- **标注**：柱顶数值 / 末点放大 / 区间高亮

## 版式

图表居中偏左，右侧可留标注空间。
