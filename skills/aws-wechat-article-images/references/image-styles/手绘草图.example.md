# 手绘草图

## 用于

边想边讲、思路推演、轻量说明。介于信息位与节奏位之间。

## 主体

圆珠笔风格的手绘线条：圈、箭头、方框，有抖动感和重复描边。

## 影调

米白纸张质感背景，只有单色线条（深蓝或墨黑），不上色。

## 文案

**可以有，用手写体中文短语。** 字少，配合箭头结构。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **笔色**：深蓝圆珠笔 / 墨黑 / 铅笔灰 / 红蓝双色
- **结构**：中心发散 / 线性推演 / 分支树 / 圈注重点
- **纸**：米白纸纹 / 方格纸 / 横线笔记本 / 纯色无纹
- **完成度**：潦草速记 / 工整誊写

## 版式

从一个中心向外引出分支。
