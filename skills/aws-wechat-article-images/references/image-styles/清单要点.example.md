# 清单要点

## 用于

要点罗列、检查清单、步骤总结。**信息位**——删掉读者记不住要点。

## 主体

3–5 个正圆形排成一列，圆内白色数字，右侧横排一行粗体中文短句。

## 影调

纯米白背景。**不要纸张、卡片、阴影或边框**——描述时要正面写「背景与画布融为一体」，写「不要卡片」无效。

## 文案

**必须有真实要点,每行控制在 4–6 字。** 明确写「画面上除这几行中文外没有任何图形、符号或图标」，否则模型会自行加 emoji 和说明小字。

## 媒介

默认**便签手写**——彩色便签错落贴在深色木桌上，签字笔手写，左上角圈起的手写序号。

本篇所有信息位配图共用同一媒介，由 [image-method.md](../image-method.md) 第四步按 `tone` / `account_type` 定；换成扁平矢量会有明显 AI 味。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **序号**：圆形数字 / 方形数字 / 勾选框 / 无序号只有点
- **条目数**：3 条 / 4 条 / 5 条
- **排列**：单列 / 双列 / 阶梯错落
- **配色**：多色序号 / 单色渐变 / 黑白加一色

## 版式

圆点列居中偏左，行高一致，左端对齐。
