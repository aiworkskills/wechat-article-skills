# 氛围留白

## 用于

章节之间的停顿、情绪转折。**节奏位**——纯粹给眼睛休息。

## 主体

极少的抽象元素（一条水平线、几个圆点），或干脆只有渐变。

## 影调

低饱和单色渐变，雾感。

## 文案

**不加字。**

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **元素**：水平线加圆点 / 纯渐变 / 一道光斑 / 细密纹理
- **色调**：雾蓝 / 暖米 / 青灰 / 淡紫
- **重心**：靠下 / 靠一侧 / 完全均匀
- **质感**：平滑渐变 / 细颗粒 / 纸纹

## 版式

大量留白，元素靠下或靠一侧。
