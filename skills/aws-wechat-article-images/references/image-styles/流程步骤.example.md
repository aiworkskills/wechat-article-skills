# 流程步骤

## 用于

教程、操作指南、方法论。**信息位**——删掉读者会看不懂步骤顺序。

## 主体

3–5 个圆角矩形横向等距排列，带箭头细线相连，当前重点那格加深描边。

## 影调

米白背景，每格一个低饱和色（靛蓝/赭黄/墨绿/砖红）。完全扁平，无阴影无渐变。

## 文案

**必须有，且必须是文章里的真实步骤名。** 每格粗体步骤名加一行小字说明。不要让模型自由发挥内容。

## 媒介

默认**马克笔白板**——手写方框、马克笔箭头、红笔圈出重点步、旧字迹残影。

本篇所有信息位配图共用同一媒介，由 [image-method.md](../image-method.md) 第四步按 `tone` / `account_type` 定；换成扁平矢量会有明显 AI 味。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **方向**：从左到右 / 从上到下 / 环形循环
- **格数**：3 格 / 4 格 / 5 格
- **连接**：实线箭头 / 虚线 / 渐变过渡 / 无连接靠间距
- **强调**：高亮当前步 / 加粗末步 / 全部等重

## 版式

横向铺满，16:9。
