# 金句卡片

## 用于

文章里最值得被单独记住的**一句话**。**节奏位**——删掉不影响理解，但读者少了一个可以截图转发的东西。

一篇最多一张。摘的必须是文章里**原本就存在**的句子，不是为配图现编的。选句标准：脱离上下文单独发出去仍然成立、且有观点（不是陈述事实）。

## 主体

一整块画面就是这句话。没有插图，没有装饰物，没有边框卡片。

## 影调

深色底浅色字，或米白底深墨字。单一底色，无渐变无阴影。

## 文案

**这个形态的全部内容就是文案。**

- 正文金句 15–30 字，居中，占画面宽度的 70–80%
- 竖排或横排均可，横排时按语义断行，不要断在词中间
- 右下角一行小字：作者名或公众号名，字号是正文的 1/4，低对比度

## 媒介

不参与本篇的媒介统一——纯字排版没有媒介属性，任何账号都用同一套：纯色底 + 一种字重的中文字体。

## 可轮换维度

每次生成从每个维度里选一个值。

- **底色**：墨黑 / 深藏青 / 米白 / 砖红
- **字体气质**：宋体（沉稳） / 黑体（利落） / 楷体（人味）
- **排列**：横排居中 / 横排左对齐 / 竖排右起
- **点缀**：无 / 句首一个引号 / 句子下方一条短横线

## 版式

字块居中，四周留白不少于画面的 15%。除了署名，画面上不出现第二组文字。
