# 概念隐喻

## 用于

抽象概念、观点段落。**节奏位**——删掉读者读不下去，但不影响理解。

## 主体

一个视觉隐喻，居中，背景空无一物。

**隐喻要绑定文章的核心张力，不是绑定主题词。** 讲「协作效率低」不要画齿轮，要画一件因为少了一环而没法用的东西。从张力出发，隐喻才有信息量；从主题词出发，只会得到一堆砖头、齿轮、灯泡这类谁看都行的通用物件。

三种构造法，选一种，在 prompt 里写死：

| 构造 | 做法 | 例 |
|---|---|---|
| **替代** | 把某个物件里本该出现的部件，换成另一个领域的东西 | 讲「用错工具」——一把钥匙的齿是螺丝刀头 |
| **融合** | 两个物件长成一个 | 讲「读者即作者」——书页翻开后是一支笔的形状 |
| **并置** | 两个物件同框，靠对照产生意义 | 讲「起点差距」——两条同样长的跑道，一条是塑胶一条是碎石 |

替代最强，并置最弱。写不出替代或融合就说明张力没找准，回到第一步重找，不要退而求其次画并置。

## 影调

奶油白背景带轻微纸纹，两三色平涂加深棕描边，圆角。

## 文案

**不加字。** 隐喻自己会说话，加字反而解释过度。写完 prompt 自查：如果不加字读者看不懂，那是隐喻没构造好，不是缺字。

## 媒介

不参与本篇的媒介统一——它不是示意图，按本模板的影调走。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **构造**：替代 / 融合 / 并置
- **笔触**：粗描边扁平 / 无描边色块 / 细线勾勒 / 水彩晕染
- **色板**：暖色三色 / 低饱和莫兰迪 / 单色加一点强调
- **视角**：正面 / 俯视 / 剖面

## 版式

主体居中，四周大量留白。
