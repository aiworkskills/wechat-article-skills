# 结构分层

## 用于

系统架构、产品结构、知识体系。**信息位**——删掉读者看不出层级关系。

## 主体

3–4 层横向长条自上而下堆叠，层内可再分小块，左侧可加竖向括号做整体标注。

## 影调

浅灰背景，每层一色，细线分隔。扁平，无立体渲染。

## 文案

**必须有真实层名。** 每层粗体层名，层内小块各有短标签。

## 可轮换维度

每次生成从每个维度里选一个值，避免同一篇文章里几张配图撞形。
Agent 应记录本篇已用过的组合并避开。

- **层数**：3 层 / 4 层 / 5 层
- **方向**：自上而下 / 同心圆 / 左右并列柱
- **层内**：再分小块 / 只有标签 / 带图标
- **标注**：左侧竖括号 / 右侧引线 / 无标注

## 版式

层叠居中，16:9。
