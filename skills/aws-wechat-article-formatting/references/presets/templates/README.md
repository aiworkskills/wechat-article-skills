# 三套模版：涂 / 画 / 省

## 为什么是三套，为什么长这样

上一轮做四个骨架失败了（见 `design/skeletons` 分支的提交信息）。这一轮换了方法：
**先做一套给用户看，认可了再往下走**，而不是先定规则再批量生成。

起点是一个实测：正文里**每篇出现几十次**的元素只有三个能加装饰——加粗、链接、
列表符号。正文段落本身只能动字号/行高/段距/缩进/对齐，那是排版不是装饰。
而上一轮四个骨架在这三个元素上**完全相同**，差异全堆在一篇可能一个都不出现的组件上。
这就是「16 套看着一样」的真正原因。

所以身份从核心层定起。三种核心层写法各自成为一套模版：

| | 核心层（每篇几十次） | 装饰的态度 |
|---|---|---|
| **涂** | 加粗是半高高亮笔 · 链接彩字加同色细线 · 空心圆 | 装饰是**涂上去的面** |
| **画** | 加粗是黑字加彩色底线 · 链接纯彩字 · 方块 | 装饰是**画出来的线** |
| **省** | 加粗是纯 900 黑字 · 链接黑字加粗实线 · 圆点 | 装饰**尽量不出现** |

往下每一层都从这个态度长出来，不是各写各的：

    层        涂                  画                    省
    h2        通栏浅底块          3px 彩色底线          26px 黑字 + 80px 上留白
    h3        浅底胶囊            3px 左竖条            19px + 48px 上留白
    引用      浅底块              2px 灰左竖线          缩进 28px
    图注      贴图的浅底带        上方一根细线托着      居中 + 宽字距
    分隔      64×8 粗色块         通栏 2px 线           一个 6px 方点
    导语      通栏浅底            上下夹线（一粗一细）  只比正文大一号
    金句      实心色块白字        左侧 6px 粗竖线       21px + 缩进
    步骤      只有序号是实心方     序号下一根短线        序号是 muted 小字
    数字      彩色巨字            行间细线              38px/300 细体
    对比      双色块              中缝竖线              上下排 + 箭头字符
    清单      灰底块              行底细线              muted 符号
    文末      8px 粗色带          顶部 3px 粗线         只有 muted 文字

**同一套里，七个语义七种形态，谁也不借谁的**——上一轮「块」的五个语义共用一张圆角卡，
就是这条没守住。

## 两条从实验里撞出来的硬规则

1. **加粗与链接的「手法集合」必须不同**。两者都用底线时读者分不清哪个能点。
   三套分别是「底 vs 彩字」「线 vs 彩字」「重字 vs 线」。
2. **列表符号不能取 `none`**。两条列表项在页面上就是两个普通段落。
   三套各占 circle / square / disc。

另见 `references/wechat-html-constraints.md` 里的「核心层的三条约束」与
「行内元素加底色：别用 padding」。
